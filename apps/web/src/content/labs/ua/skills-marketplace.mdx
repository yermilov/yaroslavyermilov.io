Я веду публічний маркетплейс **скілів, які створюю для AI-агентів** — невеликих
багаторазових інструкцій, що агент підвантажує за потреби. Це просто файли в git-
репозиторії: без збірки, без сервера — маркетплейс *і є* репозиторієм. Одне джерело
працює і для **Claude Code**, і для **Codex**, а ті самі файли `SKILL.md`
підходять для обох.

<SkillsMarketplace client:load locale="ua" />

Тут живуть три види скілів: **знаннєвий** — домен, який агент читає, щоб краще
його зрозуміти; **задачний** — збережений промпт плюс уміння виконати його добре;
і **робочий процес** — покроковий гайд для нетривіального завдання. Маркетплейс —
власний перший showcase: плагін `meta` вище є інструментарієм для створення й
підтримки нових, і кожен наступний скіл, яким я хочу поділитися, з’явиться саме тут.
